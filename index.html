INTERNET: Redes y Comunicaciones IP

Sitio de apoyo para demostrar a los estudiantes la diferencia entre una página construida con HTML puro y otra enriquecida con HTML + CSS.

Inicio HTML puro HTML + CSS

Propósito pedagógico

Este micrositio permite observar cómo una misma temática académica puede representarse primero con etiquetas HTML básicas y luego con una capa de estilos CSS. La intención es que el estudiante visualice de forma inmediata el impacto de la estructura, la semántica y el diseño.

En la versión HTML puro encontrará

  • Títulos y párrafos
  • Imágenes y enlaces
  • Marquesina
  • Tablas
  • Listas ordenadas y no ordenadas
  • Comentarios visibles en el código fuente

En la versión HTML + CSS encontrará

  • La misma temática del curso
  • Diseño más limpio y moderno
  • Tarjetas informativas
  • Galería visual
  • Distribución por columnas
  • Mayor legibilidad para contenidos académicos

Contenidos del curso representados en el sitio

Modelo OSI Arquitectura TCP/IP IPv4 e IPv6 Subneteo Enrutamiento Servicios de red

Sugerencia de uso en clase

  1. Abra primero la pestaña HTML puro.
  2. Pida a los estudiantes que inspeccionen el código fuente desde el navegador.
  3. Luego compare con la versión HTML + CSS.
  4. Discuta qué aporta la estructura HTML y qué aporta la hoja de estilos.
